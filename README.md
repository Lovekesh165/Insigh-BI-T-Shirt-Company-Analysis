# 👕 Insight BI – T-Shirt Company Analysis

## 📌 Project Overview

This project presents a **Power BI analysis of Insight BI, a T-Shirt company**.

The dashboard focuses on comparing different brands based on **discount percentage, product variety, profit percentage, and average sales price**.

The project contains **2 dashboard pages**, including a company introduction page and a brand analysis page.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze and compare different T-Shirt brands
- Identify brands offering higher discounts
- Compare brands based on product variety
- Analyze average profit percentage across brands
- Compare brands based on average sales price
- Present brand-level insights using interactive Power BI visualizations

## 📊 Dashboard Pages

### 📄 Page 1 – Company Introduction

The first page contains the **company image/branding of Insight BI**, providing an introduction to the T-Shirt company.

### 📄 Page 2 – Brand Analysis

The second page contains the following visualizations:

#### 1. Top 5 Brands by Discount %

**Visual:** Clustered Bar Chart

This visualization shows the **Top 5 brands based on Discount Percentage**.

#### 2. Top 5 Brands by Highest Number of Variety

**Visual:** Donut Chart

This visualization compares the **Top 5 brands based on the number of product varieties**.

#### 3. Top 5 Brands by Average Profit %

**Visual:** Area Chart

This visualization shows the **Top 5 brands based on Average Profit Percentage**.

#### 4. Top 5 Brands by Highest Average Sales Price

**Visual:** Ribbon Chart

This visualization compares the **Top 5 brands based on Average Sales Price**.
